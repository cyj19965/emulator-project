# 사과게임 풀이기 (크롬 확장프로그램)

사과게임(Fruit Box) 화면을 캡처해 숫자를 인식하고, 높은 점수가 나오는 드래그 순서를 별도 창에 보여줍니다.

## 설치
1. `chrome://extensions` 를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `extension` 폴더를 고릅니다.

## 사용
1. 게임 탭(https://www.gamesaien.com/game/fruit_box_a/)에서 판 전체가 보이게 합니다.
2. 게임 탭에서 툴바의 사과 아이콘을 누르면 풀이 창이 따로 열립니다 (게임 창 오른쪽).
3. **캡처 & 풀기**를 누르면 현재 탭을 캡처 → 인식 → 탐색(기본 3초)합니다.
4. 노란 사각형을 드래그합니다. 실제로 지우면 풀이 창의 판도 따라 바뀌고 다음 단계로 넘어갑니다. Space(또는 →)로 직접 넘길 수도 있습니다. 첫 단계는 빈칸 없는 사각형을 한꺼번에 모두 보여줍니다.

### 자동 실행
**자동 실행**을 누르면 크롬 디버거로 게임 탭에 연결한 뒤(탭 위에 "디버깅 중" 안내 띠가 뜹니다) 판을 다시 캡처·탐색하고, 순서대로 자동 드래그합니다. 다시 누르면 멈춥니다. 드래그 간격은 「자동 드래그 간격」에서 고릅니다.

잘못 인식한 칸은 패널의 판에서 클릭한 뒤 숫자 키(1–9, 0=빈칸)로 고치면 다시 탐색합니다.

## 권한
- `scripting`: 게임 탭에 키 입력 전달 스크립트 넣기
- `storage`: 열려 있는 풀이 창 기억
- `debugger`: 자동 드래그 (실제 마우스 입력처럼 보내기)
- `<all_urls>`: `chrome.tabs.captureVisibleTab` 으로 현재 탭을 캡처하는 데 필요
